# PvZ 动画制作器

`PvZAnimationStudio` 是面向 PC 版 `Plants vs. Zombies 1.0.0.1051` 的独立中文 WPF 编辑器。它用于制作、检查和打包分层 Reanimation，不向游戏进程注入编辑器代码。

## 当前可用能力

- 新建植物、僵尸、UI 或其他动画工程；默认保存为单文件便携工程 `*.pvza`，动画、曲线关键点与手柄、动作、属性、工作区布局、图片与图片子帧信息全部嵌入，复制给别人不再依赖原图片绝对路径。旧 `*.pvza.json` 仍可读取。
- 直接读取和重新导出 Raw `*.reanim` 与原版 PC `*.reanim.compiled`；打开时同时识别 `DEADFED4` 文件头，即使 compiled 位于任意图片目录或只使用 `.compiled` 扩展名也能读取。
- 分层画布预览、轨道选择、时间轴、播放、插入/删除帧、双击切换 K 帧。
- `Q/W/E` 选择、移动和旋转操纵器；红/蓝轴、旋转环和等比缩放手柄直接作用于画布部件。`G/R/S` 进入 Blender 式鼠标移动/旋转/缩放，左键确认，右键或 `Esc` 取消；旋转以图片视觉中心为枢轴，不再绕左上注册点打转。
- 最近 100 步会话历史：`Ctrl+Z` 逐步撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 按原顺序逐步恢复；画布、K 帧、补间、帧/轨道/动作、工程字段、数值、FPS 和图片导入都进入同一历史。
- 鼠标拖动部件，编辑 `x/y/kx/ky/sx/sy/f/a/i/font/text`。
- 从当前关键帧到右侧下一个关键帧生成线性或平滑补间；补间会烘焙位移、旋转/斜切、缩放和透明度。
- 在两个关键帧之间插入或删除整帧，以及删除两端之间的中间关键帧时，自动重新烘焙位移、旋转、缩放和透明度曲线；剩余起点和终点会立即重新连接，不再保持起点直到末帧瞬移。旧 compiled 没有曲线元数据时，会在清空待删帧之前从显式运动帧建立曲线；图片切换和动作显示标记不会被擅自平滑。
- 动作标记轨道的图片子帧 `f` 是离散的显示开关：`0` 保持显示，`-1` 才在指定帧隐藏。编辑器会强制使用常量/阶梯插值，禁止 Bezier 产生负小数而让动作提前结束；插入或删除空帧时动作范围与运动补间终点同步移动。打开旧 `.pvza`、Raw 或 compiled 时，会清理旧版本错误烘焙在 `(-1, 0)` 之间的动作标记值。
- 时间轴菱形关键帧可直接左右拖动，或用工具栏及 `Shift+←/→` 逐帧移动；拖过已有关键帧时交换顺序，不会沿途合并或吞掉帧。在时间轴空白位置随时按住左键拖动即可框选多条轨道的关键帧，`Ctrl`/`Shift` 追加选择，随后可批量拖动或用 `Delete`/`Backspace` 删除；“删除整帧”才会压缩所有轨道的时间。
- 时间轴支持轨道关键帧剪贴板：`Ctrl+C` 复制同一轨道的框选关键帧，未框选时复制当前关键帧；工具栏“复制轨道”复制当前动作范围内本轨道的全部关键帧。切换目标轨道和起始帧后用 `Ctrl+V` 粘贴，保留相对帧间距、Transform、离散图片/文字、曲线类型及 Bezier 手柄。粘贴覆盖目标时刻的旧关键点并作为一个步骤撤销/恢复；动作标记轨道与视觉轨道禁止互相误粘贴。
- 新增 Blender 风格曲线编辑器：X/Y 位移、双旋转轴、双缩放、图片子帧和透明度使用固定不同颜色，顶部图例明确标注线条用途；在曲线空白位置随时按住左键拖动即可跨多个通道框选，批量改变帧和值或批量删除。关键点跨越时采用交换重排而非自动合并；左右手柄可直接拉 Bezier 曲线，并支持自动、对齐、自由、矢量手柄以及 Bezier、线性、常量插值。普通视觉轨道可自行选择图片子帧曲线类型，但纯 `anim_*` 动作标记轨道的 `f` 固定为常量插值。
- 自动识别所有 `anim_*` 轨道，不把动作限制为内置列表；带图片的 `anim_*` 同时作为动作和可见轨道，避免睡莲等原版短动画丢失主体。
- 导入透明 PNG 或 JPG/JPEG，并把图片符号绑定到工程；选择游戏目录后可索引已解包的 `reanim/`、`images/` 与 `pvzmod/images/`。
- 可把外部 PNG、JPG 或 JPEG 直接拖入任意动画视图；编辑器会在鼠标落点居中创建独立视觉轨道并选中，多图拖入生成多条错开的轨道，随后可立即 K 帧、移动、旋转、缩放和补间，整次拖放只占一个撤销步骤。
- 精确复现原版 `MatrixFromTransform` 双轴角度、左上图片注册点、`cols/rows` 子帧，以及“JPG 颜色图 + `_.png` 灰度遮罩”的透明资源。
- 完整时间轴提供实体组合预览：机枪射手、双向射手、三线射手会组合原版独立头部实例；普通僵尸默认隐藏同一动画内的可选装备。选择具体动作后自动回到未经隐藏的原始轨道视图。
- Blender 式区域工作区：拖动分隔线调整任意面板大小；每区可切换动画视图、时间轴、曲线编辑器、资源与工程或属性检查器；右上角斜纹拖拽或 `↔/↕` 可继续拆分，`↗` 可打开共享同一工程状态的独立窗口。
- 右上角可切换动画制作、双动画视图、双时间轴、曲线动画和专注动画工作区；布局使用比例尺寸随窗口自适应，并随 `.pvza` 工程保存。
- 生成 `.reanim`、`.reanim.compiled`、Mod ZIP、贴图/动画/实体 JSONC 片段。
- 一键把动画、图片和配置合并到 `pvzmod` 分类目录；首次改写配置前生成 `.pvzstudio.bak`。

原版 `compiled/reanim` 目录的 143 个 compiled 文件已完成“读取 → 重新打包 → 再读取”回归。原版少数动画含同名轨道，工具会按顺序保留，不能擅自去重。

48 个独立植物动画和 38 个僵尸/僵尸效果动画的逐项结果、特殊组合与预期空文件见 [`ORIGINAL_ASSET_AUDIT.md`](ORIGINAL_ASSET_AUDIT.md)。

完整植物 `SeedType`、中文名称、载体 Reanimation 和 compiled 文件映射见 [`PLANT_TEMPLATE_IDS.md`](PLANT_TEMPLATE_IDS.md)。编辑器属性检查器使用同一全局目录提供 `0–48` 模板速选；`49–52` 会被识别为模式专用植物，但禁止误导出为普通 `templatePlantId`。

## 运行

本机发布版：

```text
H:\pvz\modding\dist\PvZAnimationStudio\PvZAnimationStudio.exe
```

从源码启动：

```powershell
dotnet run --project H:\pvz\modding\PvZAnimationStudio\PvZAnimationStudio.csproj -c Release
```

需要 Windows 和 .NET 8 Desktop Runtime。编辑器为 64 位独立工具；生成的 Reanimation 仍是游戏所用的 32 位 PC 格式。

## 从零制作一个植物或僵尸

1. 把角色拆成透明 PNG 部件，例如 `body`、`head`、`eye`、`arm_front`、`arm_back`、`leg_front`、`shadow`、`weapon`。
2. 新建植物或僵尸工程，设置字符串 ID、数字 ID、中文名称、说明、生命和攻击参数。
3. 导入 PNG/JPG，或直接把图片拖到动画视图落点；拖放会自动创建可独立运动的轨道，双击图片资源仍可把已有符号写入当前轨道帧。
4. 在时间轴起点按 `K`，移动到结束帧后拖动部件或修改位置、旋转、缩放，再按 `K`。
5. 回到起点，点击“线性补间”或“平滑补间”。
6. 添加或识别 `anim_idle`、`anim_attack`、`anim_blink`、`anim_die` 等动作。特殊动作只需使用新的 `anim_<动作ID>`，工具会完整保留和分类。
7. 眨眼建议把眼皮/眼睛单独放入轨道，在 `anim_blink` 范围内用 `f=-1/0` 或图片切换控制显示；编辑器不会把眨眼硬编码到身体轨道。
8. 保存 `.pvza` 便携工程，再导出 compiled 并在编辑器重新打开验证，最后生成 ZIP 或一键安装。

## 工作区、拆分与独立窗口

- 拖动面板之间的灰色分隔线，属性编辑框、动画视图和时间轴会随区域一起自适应；属性检查器使用单列宽输入框，不再把 X/Y 等字段压成四个窄列。
- 每个区域左上角的下拉框可随时切换区域类型。把两个区域都切换为动画视图即可对照不同缩放/视角；切换为两个时间轴可同时检查完整时间轴和动作局部时间轴。
- 区域右上角 `↔` 生成左右区域，`↕` 生成上下区域；也可拖动右上角斜纹拆分手柄，鼠标使用水平、垂直或对角缩放光标，不使用手型光标。
- `↗` 会创建独立窗口。独立窗口仍共享当前工程、当前帧、选择和撤销历史，也能继续拆分和切换区域类型；关闭独立窗口不会丢失工程内容。
- `×` 关闭当前分区；至少保留一个根区域。右上角工作区选择器可随时恢复预设布局。
- “曲线动画”预设同时显示动画视图、轨道时间轴和曲线编辑器。曲线区滚轮缩放时间，`Ctrl+滚轮` 缩放数值，中键平移，`Home` 适配全部，右键移动播放头。
- 时间轴和曲线区不需要切换工具：在空白位置随时按住左键拖动就是框选，点在关键帧上仍然是选择或拖动关键帧；`Ctrl`/`Shift` 可保留原选择。选中的菱形/曲线点为橙色，可一起拖动，并可用 `Delete` 或 `Backspace` 批量删除。

## 画布和历史快捷键

| 快捷键 | 功能 |
|---|---|
| `Q` | 仅选择部件 |
| `W` | 切换移动操纵器；拖中心或红/蓝轴 |
| `E` | 切换旋转操纵器；拖黄色圆环 |
| `G` | 进入鼠标移动；鼠标方向决定移动方向，左键确认，右键/`Esc` 取消 |
| `R` | 进入鼠标旋转；绕图片中心跟随鼠标方向旋转，左键确认，右键/`Esc` 取消 |
| `S` | 进入鼠标等比缩放；左键确认，右键/`Esc` 取消 |
| 空白位置左键拖动（时间轴/曲线区） | 随时框选多个关键帧；`Ctrl`/`Shift` 追加选择 |
| `Delete` / `Backspace` | 删除时间轴或曲线区的全部已选关键帧 |
| `Ctrl+C` / `Ctrl+V`（时间轴） | 复制同一轨道的已选/当前关键帧，并以当前帧为起点粘贴到当前轨道 |
| 方向键 / `Shift`+方向键 | 1 / 10 像素微调 |
| `K` / `Shift+K` | 设置 / 清除当前 K 帧 |
| `Ctrl+Z` | 逐步撤销，最多保留最近 100 步 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 逐步恢复；撤销后产生新编辑会清除旧恢复分支 |

## 工程和输出目录

```text
<工程>.pvza                              # 单文件便携工程：project.json + 内嵌 PNG
<旧工程>.pvza.json                       # 旧版外部路径 JSON，只读兼容并建议另存为 .pvza
pvzmod/animations/plants/<id>/           # 植物动作
pvzmod/animations/zombies/<id>/          # 僵尸动作
pvzmod/images/plants/<id>/               # 植物 PNG
pvzmod/images/zombies/<id>/               # 僵尸 PNG
pvzmod/config/resources/textures.jsonc   # 图片注册
pvzmod/config/resources/animations.jsonc # 动画、动作、事件注册
pvzmod/config/plants/custom_plants.jsonc # 新植物配置
pvzmod/config/zombies/                    # 生成的新僵尸配置
```

ZIP 中使用 `generated/<id>/*.fragment.jsonc`，便于人工审查后合并；“一键安装”使用字符串 ID 更新对应数组，保留文件其他注释和条目。

## Raw 与 compiled

- Raw 是 XML 片段，适合版本管理和人工审阅。
- compiled 使用原版 PC `DEADFED4 + zlib + B393B4C0` 布局；输出保持 Definition/Track/Transform 的 16/12/44 字节协议。
- “导出 compiled”强制使用 compiled 编码器并规范化完整后缀；“打开动画”先检查 `DEADFED4` Cookie，再用扩展名分流，避免导出文件在其他目录中被过滤或误当 Raw XML。
- 文件中的旧指针只作为占位，不会被解引用；导出时重建字符串数据。
- 省略字段表示继承前一帧；设置 K 帧、生成补间、插入/删除整帧以及删除中间关键帧后的曲线重烘焙会写入显式运动数值。

## 当前边界

编辑器与格式打包器已经可用，但“文件可生成”不等于“游戏运行时已经支持真正新实体”。当前 DLL 仍缺少自定义 `ReanimatorDefinition` 注入、自定义僵尸运行时和完整动作事件控制器。因此：

- 可以安全编辑、重打包和登记原创动画资源。
- 自定义植物配置可接入现有模板载体；原创动画最终替换仍取决于后续运行时 Definition 注入。
- 僵尸配置目前生成到独立文件，等待 `custom_zombie_runtime` 接入，避免假装已经能在游戏中生成真正新僵尸。
- 曲线在编辑器中保留 Bezier 关键点与手柄，同时烘焙为原版可读取的逐帧数值；当前还没有骨骼 IK、曲线修改器和音频时间轴。

## 构建与回归

```powershell
dotnet build H:\pvz\modding\PvZAnimationStudio\PvZAnimationStudio.csproj -c Release
dotnet run --project H:\pvz\modding\PvZAnimationStudio.Tests\PvZAnimationStudio.Tests.csproj -c Release
dotnet run --project H:\pvz\modding\PvZAnimationStudio.Tests\PvZAnimationStudio.Tests.csproj -c Release -- H:\pvz\compiled\reanim
```

第三条命令会验证本地全部原版 compiled。测试只在临时目录写入重打包文件，不覆盖原版资源。
